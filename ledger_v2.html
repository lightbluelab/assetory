EASY LEDGER资产与现金流账本
使用说明

家庭资产记账本

这是一个本地优先的家庭资产管理工具。网页程序与账本数据分开保存：ledger_v2.html 是程序，*.json 是每一本账本的数据。将两者一起分享即可使用。

开始使用

  1. 用 Chrome 或 Edge 直接打开本 HTML 文件。
  2. 点击“账本管理”中的“新建账本”，输入账本名称，并选择 JSON 文件的保存位置。建议与 HTML 放在同一文件夹。
  3. 添加月份；系统会继承最近上月的资产和汇率，不复制流水。
  4. 在资产负债表维护期末持仓、价格或金额，在流水表记录收入、支出、转账、买卖和还款。
  5. 月末更新股票价格和汇率，检查对账提示及整体趋势。

每月记账原则

  • 收入、支出和转账应选择对应现金账户；转账不改变净资产。
  • 买入、卖出会同时影响现金和投资持仓。股票按数量变化，基金和固定资产按金额变化。
  • 还款会同时减少现金和负债。
  • 优先用流水解释余额变化，不要直接修改继承来的现金、负债或持仓。出现对账提醒时，检查遗漏的流水或手工改动。
  • 修改历史月份后，使用“同步到下月”或“同步到后续所有月份”重建后续期初。

数据、备份与联网

  • JSON 是唯一的数据源，请定期复制备份；删除月份或批量改动前尤其应备份。
  • 浏览器只在本地记住文件句柄，数据仍以 JSON 文件为准。换电脑后重新打开同一 JSON 即可。
  • 自动股价和汇率会访问公开接口；不希望联网时可直接手工填写价格和汇率。
  • 若某台设备直接打开 HTML 后无法选择或保存文件，可改用本地静态服务器，例如 python3 -m http.server 8000，再访问 http://localhost:8000/ledger_v2.html。

让 AI 修改本网页

样式、文案、图表和新增展示字段通常可以直接修改。涉及数据和计算时，请把以下约束一并告诉 AI：

  • 保持 JSON 兼容；新增字段必须允许旧账本缺失并提供默认值，不能静默丢弃或重写用户数据。
  • ASSET_CLASSES、FLOW_TYPES、applyFlow、rebuildChildFromParent、syncToAll、reconcile 共同维护流水联动、跨月同步和对账，修改流水含义时必须一起检查。
  • 流水的 fromIdx / toIdx 引用资产列表下标；重排或删除资产时必须保留现有重映射逻辑。
  • 不要把数据上传到服务器或改变本地 JSON 保存机制。涉及大范围逻辑修改时，优先生成新的 ledger_vN.html 版本并保留旧版回退。
